# SC2 Gaming Website

GitHub Pages-ready static gaming website.

## Deploy
1. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder to your repository.
2. In GitHub: Settings → Pages → Deploy from branch → select your main branch and `/ (root)`.
3. Open the generated GitHub Pages URL.

The player profile and leaderboard use browser localStorage. No backend is required.
